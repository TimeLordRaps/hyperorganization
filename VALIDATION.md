# Validation

The receipt for `hyperoptimization` 0.1.0.dev0, 2026-10-11. Everything below was observed in one session by one author. Nothing here has been run by anyone else, and no hosted workflow has run on this repository. Part of the checking was done by reference implementations that subagents wrote from a specification; they are untrusted model output and are described as such where they appear.

## Coordinates

* Repository `hyperoptimization`, local only (it has no remote; see [PROVENANCE.md](PROVENANCE.md) and `TECHNICAL_DEBT.md` HO-009), branch `main`, parent commit `7e039fe`. The commit carrying this receipt adds the exchange layer: the modules `knowledge`, `comprehension`, `deals` and `entangled`, the decisions D24 to D30, the specification `L1_exchange.hm`, three reference implementations with the runner that compares the package against them, and the checks listed below. The manifest binds the bytes.
* The implementation, tests, scripts, data, specifications and the three generated or load-bearing documents are byte-bound in [`validation/source-manifest.json`](validation/source-manifest.json): 66 files, digest of its canonical `files` mapping `92d44b4736120e0dddc35184ced3dcbd9159a7a5dcf222d5dfcf98c66e89448b`. The manifest identifies tested bytes. It does not sign or certify them.
* CPython 3.11.15 for the main run, and the same suite under CPython 3.10.20 and 3.13.14, on Linux 6.18.44. pytest 9.1.1, pytest-timeout 2.4.0, sympy 1.14.0 (needed only by the quantum reference implementation and its tests), ruff 0.16.10, coverage 7.16.2, uv 0.8.17 (used to build). `pyproject.toml` supplies `-vv -s --durations=10 --timeout=60`; the runs below used `--timeout=120` (coverage 400, unpacked sdist 240) because several ran at once.
* **No runtime dependencies.** The package imports only the standard library, and none of the packages whose records it holds.
* **What ran on which bytes.** The suites, the differential runner, the cross-check, both specification lints, the source distribution and the wheel ran on the final bytes. Coverage and the mutation runs ran one step earlier, before a last pass that reworded comments, docstrings and prose outside `src/`; `src/` is byte-identical before and after (compared with `diff -r`), and the files that changed are the documents, the specification's comments, the oracle scripts' headers and the runner's and one test's docstring.
* Records of other packages, each a snapshot with the commit it was read at: hyperethics `a13770716f57` (gate costs), hyperlogic `09231650d419` (Gödel–Löb prover verdicts), hyperstratum `87aadc390fea` (the static family graph, digest `b56f1a3c61d9…`, and the live scan). Checked against, in this session: hyperethics `a515d89` (cross-verification) and hypermath `a340179` (specification lint).

* **831 passed, zero skips**, under CPython 3.11 with `PYTHONHASHSEED` 0, 1, 3 and 4242 (125 to 133 s each, three or four runs at a time), under 3.10 (165 s) and under 3.13 (105 s), and from the unpacked source distribution under 3.13 (102 s). By file: clauses 82, comprehension 25, deals 23, decisions 90, design numbers 12, documents 3, entangled 25, entrenchment 13, family 23, ground 11, knowledge 22, loop 70, maintenance 10, manifest 4, oracles 17, ordinal 28, phases 19, poly 18, quorum 57, renewal 43, report 13, spec 91, surprisal 77, viability 55. The longest single test is about 8 s. Ruff passes with no findings.
* **Coverage, line and branch: 99%** (3306 statements, 2 missed; 1422 branches, 1 partial). Every module is at 100% except `__main__.py`, whose two missed lines are the body of `if __name__ == "__main__":`. They run only in a subprocess, which this measurement does not follow; the subprocess tests exercise that path. (The coverage run takes 407 s: it is the slowest way to run the suite.)
* **Mutation testing.** Of the layer added here, **147 hand-written mutants, all killed** on the final tree (knowledge and the kernel view 14, comprehension 29, deals 38, entangled 58, the report 8); each is judged by its own module's tests with the document-drift tests deselected, since any change that moves a printed number would fail those. One mutant of the entangled module targeted code that had since been refactored away (its text no longer existed) and was replaced by a live one; the live one **survived**, because every shipped strategy decodes one outcome to one output, so adding the probabilities of two outcomes that decode to the same output was never exercised. A strategy with a spare qubit whose outcome is ignored now exercises it, and the mutant is killed (audit 5). Of the earlier layers, the 131 mutants of the previous receipt were re-run on this tree: **130 killed and 1 survivor**, `minimal_covers` with `c < candidate` for `c <= candidate`, which is equivalent (audit 3: identical results on 66,067 networks of up to four parties). One of the 131 (`rep-family`) had targeted report text this layer rewrote; it was replaced by a live mutant of the new text, which is killed. Each is judged first by its module's own tests and, if it survives those, by the whole suite. The mutants are a hand-picked sample of small changes. Killing them shows the tests notice those changes; it does not show the code correct.
* **Every failure clause of every check can fire.** `tests/test_clauses.py` reads the failure clauses out of the source of `decisions.py` (every `problems.append(...)`), breaks one function for each, and requires the witness to say what the clause says; a clause no breakage reaches fails the suite (negative control: an unreachable clause is reported by decision and line).
* **The numbers the design quotes are the numbers the models compute.** `tests/test_design_numbers.py` recomputes every count and value that DESIGN.md section 14 and the README quote (717, 126 and 249 of 1,092 splits; 9 of 14 territorial games; 236, 3 and 0 menus; 13, 2, 2 and 4 footprints; 6.3 and 2.7 bits; 577/676 and its distance from the Tsirelson value) and requires the document to contain the sentence built from them. Run against a copy of the document with nine numbers altered, ten of its twelve tests fail and each says which number changed and what the document says instead; the two that pass test the guard's own handling of a missing sentence and of whitespace.
* **Reference implementations.** `scripts/oracle_comprehension.py`, `oracle_quantum.py` and `oracle_price.py` were written by subagents from a written specification alone (they never saw this package) and are run against it by `scripts/differential_oracles.py`. `python scripts/differential_oracles.py --full` (34 s, exit 0): 3,473 comparisons for the footprint and quorum (1,500 instances, 1,173 of them makeable, 800 graphs), 1,206 for the price test (6 hand-derived cases, 1,000 small and 200 larger option sets, 3,389 efficient options, 492 of them price-invisible), 38 for the quantum values (12 GHZ-type states, 25 random CHSH strategies, the magic square); no disagreement. Each stage runs in its own process under a deadline and reports UNKNOWN, never agreement, if it is killed or lacks `sympy`. `tests/test_oracles.py` (17 tests) plants a slip in the package and in each oracle and requires disagreement. Agreement shows that implementation slips of these kinds are caught; both sides were written from the same text, so it does not show the definitions right (HO-024). A first price oracle built on sympy's simplex was dropped: it does not finish for some hash seeds on a six-option set and returns points that violate its own constraints (HO-025; `scripts/probe_sympy_lpmax.py` reproduces both).
* **Cross-check against hyperethics' own code** at `a515d89`: gate cost is at most gate size times the dearest price on 1,178 of its random gates; the smallest system that obeys its rule and costs at least a stake has an amendment gate of `max(k+1, m*)` on 120 instances, by exhaustive search that builds each candidate as a hyperethics `Governance`.
* **Specification lint** with the family's translator (hypermath `a340179`): exit 0 for both `L0_viability.hm` and `L1_exchange.hm`, 0 statements outside the translatable fragment. The axioms are prose in comments; the translator does not translate derives or non-derives, so nothing mechanical ties the specifications to the code except `tests/test_spec.py` (91 tests: every declared name has a row, every row names code, a test and a decision that exist, and the owner's messages are in the specifications and in PROVENANCE exactly as sent, including the doubled space in the third).
* **Packaging.** An sdist and a wheel were built with `uv build` from a clean copy of the tree. `scripts/check_sdist.py` finds all 66 listed files in the sdist, byte for byte (79 files in it). The wheel, installed into a clean CPython 3.13 environment, imports the new modules, and `python -m hyperoptimization decisions` is byte-identical to `DECISIONS.md` (30 decisions, 24 with checks, all 24 holding). The unpacked sdist's own suite passes (831) under 3.13.
* **Defects found and repaired while closing this out**, each reproduced first (register rows HO-025, HO-026 and audit 5): a price reference implementation that hung for some hash seeds; two commutation caches with no bound; three import-order lint failures that the previous commit did not have, introduced by later edits to import blocks after a lint run I had reported clean; a test gap in the output merging of `table`. Earlier in this layer's construction, found by a subagent's review whose claims I verified one by one: several overclaims in the documentation (corrected), one wrong claim of the reviewer's about ties in the price test (refuted by an exact counterexample), and guessed sample-size floors in my first test drafts (replaced by exact counts).

## What the results are evidence of

* `[FORM]` results (the greatest sustaining law and its uniqueness, rank certificates, exemption is fatal, quorum duality and the single critical point, the dual-variable identity of the loops, closed forms for the renewal chain, prices as surprisal brackets, protection as the weakest link, the phase of a dependency graph, self-maintenance as a greatest fixed point, Goodstein descent; and in the exchange layer, soundness and exactness of a partial view, the cover and robust quorum against every group of people, dominance and the price certificates, the exact quantum values) were checked exactly in rationals or exhaustively on every finite structure of a stated size, against definitions that share no code with the implementation, or against a reference written by someone who had not seen it.
* `[FRAME]` results hold inside stated assumptions (independent seats, mean-field loops, a birth–death chain with repair only while the body holds, surprisal as price, full support as free will, the Löb ring as the logic of proof-checked approval, a recorded snapshot of the family; in the exchange layer, ignorance as pessimism, understanding as a set, a deal as a vector with four yes-or-no coherence dimensions, an entangled decision as measurements on a shared state). Each assumption is a decision in `DECISIONS.md` with what would refute it.
* `[HYPER]` and `[OPEN]` items carry no check on purpose: that physical reality adheres to such a structure (D17), why persistence is the right thing to optimize (D16), that hyperoptimization closes the family's open items (D18; the first passes do not support it), that institutional decisions can be entangled (D28), that understanding can be measured (D29), and that win-win survives rival freedoms without an exchange rule (D30).

## Not observed

* **No hosted workflow has run on this repository.** The conformance workflow was copied unchanged. Its install step falls back from the declared extras to fewer when an install fails, so a missing `sympy` would fail the oracle tests (they do not skip), not hide. The one Windows failure that could be reproduced here (a cp1252 pipe) is fixed and tested; Windows, macOS and the hosted 3.10 and 3.13 legs are unrun (HO-005). The oracle runner's deadline uses `subprocess` and is portable in design, but it was only run on Linux; `scripts/probe_sympy_lpmax.py` needs `SIGALRM` for half of what it does.
* No independent reviewer and no external reproduction. Hash-seed independence was checked by subprocess runs, not by a second machine.
* **The reference implementations are model-written from the design's own text** (HO-024). A mistake in a definition would be in both.
* Nothing quantum has been run on a physical system; the Tsirelson value is cited, not proved; the quantum engine is exact and dense and out of reach beyond about six qubits (HO-022, HO-023). The state-dependence formula covers one family of states and one set of measurements.
* Understanding has no instrument (D29, HO-020); institutional entanglement has no witness (D28); win-win holds here because the permissions modelled are not rival (D30, HO-021).
* The goldens are snapshots (HO-004). If hyperethics, hyperlogic or hyperstratum change what they record, the tests keep passing against the old numbers until the goldens are regenerated deliberately.
* The loop thresholds are mean-field and the repair model is a chain; no real institution was measured (D03, D09, HO-001, HO-002, HO-003).
* The family findings (D22, D23) are about one snapshot of two records. A citation is evidence of mention, not of need; the keyword table misses synonyms and counts a word in any sense; the reading of which four open items this package touches was by hand and cannot be rerun (HO-017, HO-018). The family footprints quoted in section 14.2 are loads in that model of the record.
* The repository is not on the hosting platform. Creating it is the owner's step (HO-009).

## What would invalidate it

Any change to a listed file (`tests/test_manifest.py` fails until the manifest is regenerated, which is the moment to rerun the checks above, the linter last); a regenerated golden; a change to hyperethics, hyperlogic, hyperstratum or hypermath that the records or cross-checks read; a new CPython minor version; a new sympy release (the quantum reference uses it for exact linear algebra).
